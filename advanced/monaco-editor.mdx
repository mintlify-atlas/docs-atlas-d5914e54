# Monaco Editor

Monaco Editor is the code editor that powers VS Code and can be used standalone in web applications. It provides rich IntelliSense, validation, and editing features for over 50 languages.

## Architecture Overview

Monaco Editor is structured in layers:

<Info>
**Editor Layers:**
- **Core Editor** (`src/vs/editor/browser/`): Rendering, view management, text buffer
- **Common Layer** (`src/vs/editor/common/`): Model, language services, tokenization
- **Standalone** (`src/vs/editor/standalone/`): Standalone editor API and bootstrapping
- **Contrib** (`src/vs/editor/contrib/`): Feature contributions (find, autocomplete, etc.)
</Info>

## Text Models

The text model is the core data structure representing document content:

### Model Creation

```typescript
// Create model
const model = monaco.editor.createModel(
  'const x = 1;',
  'typescript',
  monaco.Uri.file('/path/to/file.ts')
);

// Set model on editor
editor.setModel(model);

// Get current model
const currentModel = editor.getModel();
```

### Model Operations

```typescript
// Read content
const value = model.getValue();
const lineCount = model.getLineCount();
const line = model.getLineContent(5);

// Modify content
model.setValue('new content');

model.applyEdits([{
  range: new monaco.Range(1, 1, 1, 1),
  text: '// Comment\n'
}]);

// Push edit operation (with undo/redo support)
model.pushEditOperations(
  [],
  [{
    range: new monaco.Range(1, 1, 1, 1),
    text: 'inserted text'
  }],
  () => null
);
```

### Model Events

```typescript
// Listen to content changes
model.onDidChangeContent((e) => {
  console.log('Content changed:', e.changes);
  e.changes.forEach(change => {
    console.log(`Range: ${change.range}, Text: ${change.text}`);
  });
});

// Language change
model.onDidChangeLanguage((e) => {
  console.log(`Language changed to: ${e.newLanguage}`);
});
```

<Warning>
**Memory Management**: Always dispose models when no longer needed. Models are NOT automatically disposed when editors are disposed.

```typescript
model.dispose(); // Must be called explicitly
```
</Warning>

## Language Features

Monaco supports rich language features through providers:

### Registering Completion Provider

```typescript
monaco.languages.registerCompletionItemProvider('javascript', {
  provideCompletionItems: (model, position, context, token) => {
    const word = model.getWordUntilPosition(position);
    const range = {
      startLineNumber: position.lineNumber,
      endLineNumber: position.lineNumber,
      startColumn: word.startColumn,
      endColumn: word.endColumn
    };
    
    return {
      suggestions: [
        {
          label: 'myFunction',
          kind: monaco.languages.CompletionItemKind.Function,
          documentation: 'My custom function',
          insertText: 'myFunction(${1:param})',
          insertTextRules: monaco.languages.CompletionItemInsertTextRule.InsertAsSnippet,
          range: range
        }
      ]
    };
  }
});
```

### Hover Provider

```typescript
monaco.languages.registerHoverProvider('javascript', {
  provideHover: (model, position, token) => {
    const word = model.getWordAtPosition(position);
    if (!word) return null;
    
    return {
      range: new monaco.Range(
        position.lineNumber,
        word.startColumn,
        position.lineNumber,
        word.endColumn
      ),
      contents: [
        { value: '**Function Documentation**' },
        { value: '```typescript\nfunction myFunc(): void\n```' }
      ]
    };
  }
});
```

### Code Actions Provider

```typescript
monaco.languages.registerCodeActionProvider('javascript', {
  provideCodeActions: (model, range, context, token) => {
    // Return quick fixes and refactorings
    return {
      actions: [
        {
          title: 'Convert to arrow function',
          diagnostics: context.markers,
          kind: 'refactor.rewrite',
          edit: {
            edits: [{
              resource: model.uri,
              versionId: model.getVersionId(),
              textEdit: {
                range: range,
                text: '() => {}'
              }
            }]
          },
          isPreferred: true
        }
      ],
      dispose: () => {}
    };
  }
});
```

### Definition Provider

```typescript
monaco.languages.registerDefinitionProvider('javascript', {
  provideDefinition: (model, position, token) => {
    // Return location of definition
    return {
      uri: model.uri,
      range: new monaco.Range(10, 5, 10, 15)
    };
  }
});
```

## Web Worker Integration

For language services in web workers:

```typescript
// Configure worker paths
self.MonacoEnvironment = {
  getWorkerUrl: function (moduleId, label) {
    if (label === 'json') {
      return './json.worker.bundle.js';
    }
    if (label === 'css' || label === 'scss' || label === 'less') {
      return './css.worker.bundle.js';
    }
    if (label === 'html' || label === 'handlebars' || label === 'razor') {
      return './html.worker.bundle.js';
    }
    if (label === 'typescript' || label === 'javascript') {
      return './ts.worker.bundle.js';
    }
    return './editor.worker.bundle.js';
  }
};
```

## Performance Best Practices

<Warning>
**Performance Tips:**
1. **Dispose Resources**: Always dispose editors and models
2. **Lazy Load**: Load Monaco asynchronously when needed
3. **Limit Models**: Keep only necessary models in memory
4. **Debounce Updates**: Batch model updates where possible
5. **Virtual Scrolling**: Monaco handles large files efficiently via virtual scrolling
</Warning>
