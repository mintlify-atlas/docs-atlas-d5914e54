The **Monaco Editor** is the heart of VS Code's editing experience. It's a standalone, browser-based code editor that provides rich IntelliSense, validation, and editing features. Located in `src/vs/editor/`, it can be used independently of VS Code.

## What is Monaco?

Monaco is the code editor that powers VS Code. Key characteristics:

  <Card title="Fast & Efficient" icon="bolt">

## Text Model

The text model represents the actual document content and is completely independent of how it's displayed.

**Location:** `src/vs/editor/common/model.ts`

<CodeGroup>
```typescript ITextModel Interface
interface ITextModel extends ITextBuffer {
  readonly uri: URI;
  readonly id: string;
  
  // Content
  getValue(): string;
  getValueLength(): number;
  getValueInRange(range: IRange): string;
  getLineCount(): number;
  getLineContent(lineNumber: number): string;
  
  // Editing
  applyEdits(operations: IIdentifiedSingleEditOperation[]): void;
  pushEditOperations(
    beforeCursorState: Selection[],
    editOperations: IIdentifiedSingleEditOperation[],
    cursorStateComputer: ICursorStateComputer
  ): Selection[] | null;
  
  // Events
  readonly onDidChangeContent: Event<IModelContentChangedEvent>;
  readonly onDidChangeLanguage: Event<IModelLanguageChangedEvent>;
  readonly onDidChangeOptions: Event<IModelOptionsChangedEvent>;
}
```

```typescript Creating a Text Model
import { createTextModel } from 'vs/editor/common/model/textModel';

const model = createTextModel(
  'const x = 10;\nconsole.log(x);',
  'javascript',
  URI.file('/path/to/file.js')
);

// Read content
console.log(model.getLineCount()); // 2
console.log(model.getLineContent(1)); // 'const x = 10;'

// Listen for changes
model.onDidChangeContent(e => {
  console.log('Content changed:', e.changes);
});
```

```typescript Editing the Model
// Single edit
model.applyEdits([{
  range: new Range(1, 1, 1, 1),
  text: '// Comment\n'
}]);

// Batch edits with cursor tracking
const newCursorState = model.pushEditOperations(
  [new Selection(1, 1, 1, 1)],
  [{
    range: new Range(1, 7, 1, 7),
    text: 'y = 20, '
  }],
  (inverseEditOperations) => {
    // Compute new cursor position
    return [new Selection(1, 15, 1, 15)];
  }
);
```
</CodeGroup>

<Note>
Text models use **piece table** data structures for efficient editing operations, supporting O(log n) complexity for most operations even on large files.
</Note>

## View Model

The view model transforms the text model into visual representation, handling:

- Line wrapping
- Folding (code collapse)
- Decorations (highlights, error squiggles)
- Hidden areas
- Viewport calculations

**Location:** `src/vs/editor/common/viewModel.ts:31`

<CodeGroup>
```typescript IViewModel Interface

  convertModelPositionToViewPosition(modelPosition: Position): Position;

  getViewLineCount(): number;
  getViewLineContent(viewLineNumber: number): string;
  getViewLineMinColumn(viewLineNumber: number): number;
  getViewLineMaxColumn(viewLineNumber: number): number;
  
  // Decorations

  // Events
  readonly onEvent: Event<OutgoingViewModelEvent>;
```

```typescript View-Model Coordinates
// Model has 1 wrapped line that displays as 2 view lines
// Model line 1: "This is a very long line that wraps"
// View line 1:  "This is a very long"
// View line 2:  "line that wraps"
```

### Creating a Contribution

<CodeGroup>
```typescript Editor Contribution
import { 
  IEditorContribution,
  EditorContributionInstantiation
} from 'vs/editor/common/editorCommon';
import { registerEditorContribution } from 'vs/editor/browser/editorExtensions';

class MyEditorContribution implements IEditorContribution {
  static readonly ID = 'editor.contrib.myFeature';

  constructor(
    private editor: ICodeEditor,
    @IContextKeyService private contextKeyService: IContextKeyService
  ) {
    this.editor.onDidChangeModel(() => {
      this.onModelChanged();
    });
  }

  getId(): string {
    return MyEditorContribution.ID;
  }

  dispose(): void {
    // Cleanup
  }

  private onModelChanged(): void {
    // Handle model change
  }
}

// Register the contribution
registerEditorContribution(
  MyEditorContribution.ID,
  MyEditorContribution,
  EditorContributionInstantiation.Eager // or Lazy
);
```

```typescript Editor Action
import { EditorAction, registerEditorAction } from 'vs/editor/browser/editorExtensions';

class MyEditorAction extends EditorAction {
  constructor() {
    super({
      id: 'editor.action.myAction',
      label: 'My Custom Action',
      alias: 'My Custom Action',
      precondition: ContextKeyExpr.and(
        EditorContextKeys.writable,
        EditorContextKeys.hasNonEmptySelection
      ),
      kbOpts: {
        kbExpr: EditorContextKeys.textInputFocus,
        primary: KeyMod.CtrlCmd | KeyCode.KeyK,
        weight: KeybindingWeight.EditorContrib
      }
    });
  }

  run(accessor: ServicesAccessor, editor: ICodeEditor): void {
    const selection = editor.getSelection();
    if (!selection) return;

    const model = editor.getModel();
    if (!model) return;

    const text = model.getValueInRange(selection);
    // Process text...
  }
}

registerEditorAction(MyEditorAction);
```

<Accordion title="Hover Provider">
Shows information when hovering over code.

```typescript
monaco.languages.registerHoverProvider('javascript', {
  provideHover: (model, position, token) => {
    const word = model.getWordAtPosition(position);
    if (!word) return null;

    return {
      range: new monaco.Range(
        position.lineNumber,
        word.startColumn,
        position.lineNumber,
        word.endColumn
      ),
      contents: [
        { value: '**' + word.word + '**' },
        { value: 'Detailed information about ' + word.word }
      ]
    };
  }
});
```
</Accordion>

<Accordion title="Diagnostic Provider (Validation)">
Provides error and warning markers.

```typescript
monaco.editor.onDidCreateModel(model => {
  function validate() {
    const markers: monaco.editor.IMarkerData[] = [];
    const text = model.getValue();
    
    // Simple validation: find 'TODO' comments
    const lines = text.split('\n');
    lines.forEach((line, i) => {
      if (line.includes('TODO')) {
        markers.push({
          severity: monaco.MarkerSeverity.Warning,
          message: 'TODO found',
          startLineNumber: i + 1,
          startColumn: line.indexOf('TODO') + 1,
          endLineNumber: i + 1,
          endColumn: line.indexOf('TODO') + 5
        });
      }
    });

    monaco.editor.setModelMarkers(model, 'myValidator', markers);
  }

  let handle: any;
  model.onDidChangeContent(() => {
    clearTimeout(handle);
    handle = setTimeout(validate, 500);
  });
  
  validate();
});
```
</Accordion>

<Accordion title="Code Action Provider">
Provides quick fixes and refactorings.

```typescript
monaco.languages.registerCodeActionProvider('javascript', {
  provideCodeActions: (model, range, context, token) => {
    const actions: monaco.languages.CodeAction[] = [];
    
    // Add action for each diagnostic
    for (const marker of context.markers) {
      if (marker.message.includes('TODO')) {
        actions.push({
          title: 'Remove TODO',
          kind: 'quickfix',
          diagnostics: [marker],
          edit: {
            edits: [{
              resource: model.uri,
              textEdit: {
                range: marker,
                text: ''
              }
            }]
          }
        });
      }
    }
    
    return {
      actions,
      dispose: () => {}
    };
  }
});
```
</Accordion>
