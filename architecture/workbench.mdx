The **workbench** is VS Code's main UI shell that brings together the editor, sidebar, panels, and other visual components. Located in `src/vs/workbench/`, it sits above the platform and editor layers to create the complete VS Code experience.

## Workbench Architecture

The workbench is organized into distinct visual **parts** that users see and interact with:

## Workbench Parts

Each part is a distinct UI region with specific responsibilities. Located in `src/vs/workbench/browser/parts/`.

### Activity Bar

The vertical bar on the left (or right) that switches between views.

<CodeGroup>
```typescript Activity Bar Part
// src/vs/workbench/browser/parts/activitybar/
interface IActivityBarPart extends IPart {
  // Show/hide activity bar
  readonly onDidChange: Event<void>;
  
  // Get visible actions
  getActions(): readonly IAction[];
  
  // Focus
  focus(): void;
}
```

```typescript Activity Bar Actions
// Each icon in the activity bar
interface IActivity {
  id: string;
  name: string;
  keybindingId?: string;
  cssClass?: string;
  iconUrl?: URI;
}

// Register a new activity
ActivityRegistry.registerActivity({
  id: 'workbench.view.extension.myView',
  name: 'My View',
  iconUrl: URI.parse('myicon.svg')
});
```
</CodeGroup>

<Note>
The Activity Bar can be positioned on the left (default) or right, or hidden entirely. Users control this via View menu.
</Note>

```typescript Creating a Viewlet
class MyViewlet extends Viewlet {
  static readonly ID = 'workbench.view.myViewlet';

  constructor(
    @ITelemetryService telemetryService: ITelemetryService,
    @IThemeService themeService: IThemeService,
    @IStorageService storageService: IStorageService
  ) {
    super(MyViewlet.ID, telemetryService, themeService, storageService);
  }

      MyViewPaneContainer,
      parent

  }

  ViewletDescriptor.create(
    MyViewlet,
    MyViewlet.ID,
    'My Viewlet',
    'myViewletIcon',
    5 // Order
  )
);
```
</CodeGroup>

- **Source Control** (`scm/`) - Git and version control
- **Debug** (`debug/`) - Debugging UI
- **Extensions** (`extensions/`) - Extension marketplace

### Editor Area

The central area that hosts one or more editor groups in split layouts.

<CodeGroup>
```typescript Editor Part
interface IEditorPart extends IEditorGroupsService {
  // Editor groups
  readonly groups: readonly IEditorGroup[];
  readonly activeGroup: IEditorGroup;
  readonly count: number;
  
  // Group management
  addGroup(
    location: IEditorGroup | GroupDirection,
    direction: GroupDirection
  ): IEditorGroup;
  
  removeGroup(group: IEditorGroup): void;
  moveGroup(group: IEditorGroup, location: IEditorGroup, direction: GroupDirection): void;
  
  // Layout
  readonly orientation: GroupOrientation;
  setGroupOrientation(orientation: GroupOrientation): void;
  
  // Events
  readonly onDidAddGroup: Event<IEditorGroup>;
  readonly onDidRemoveGroup: Event<IEditorGroup>;
  readonly onDidActiveGroupChange: Event<IEditorGroup>;
}
```

```typescript Editor Groups
interface IEditorGroup {
  readonly id: number;
  readonly index: number;
  readonly label: string;
  
  // Editors in this group
  readonly editors: readonly IEditorInput[];
  readonly activeEditor: IEditorInput | null;
  readonly count: number;
  
  // Open/close editors
  openEditor(
    editor: IEditorInput,
    options?: IEditorOptions
  ): Promise<IEditorPane | undefined>;
  
  closeEditor(editor?: IEditorInput): Promise<void>;
  closeAllEditors(): Promise<void>;
  
  // Events
  readonly onDidOpenEditor: Event<IEditorOpenEvent>;
  readonly onDidCloseEditor: Event<IEditorCloseEvent>;
  readonly onDidActiveEditorChange: Event<void>;
}
```

```typescript Opening Editors
import { IEditorService } from 'vs/workbench/services/editor/common/editorService';

class MyComponent {
  constructor(
    @IEditorService private editorService: IEditorService
  ) {}

  async openFile(uri: URI) {
    // Open in active group
    await this.editorService.openEditor({
      resource: uri,
      options: { pinned: true }
    });
    
    // Open in specific group
    const group = this.editorService.editorGroups.groups[0];
    await this.editorService.openEditor({
      resource: uri
    }, group);
    
    // Open to the side
    await this.editorService.openEditor({
      resource: uri
    }, SIDE_GROUP);
  }
}
```
</CodeGroup>

<Tip>
Editor groups support complex layouts: horizontal splits, vertical splits, and grid layouts with any number of groups.
</Tip>

```typescript Creating a Tree View
class MyTreeView extends TreeView {
  constructor(
    @IInstantiationService instantiationService: IInstantiationService,
    @IViewDescriptorService viewDescriptorService: IViewDescriptorService,
    @IThemeService themeService: IThemeService
  ) {
    super('myView', 'My View', instantiationService, viewDescriptorService, themeService);
  }

  protected renderBody(container: HTMLElement): void {
    super.renderBody(container);
    
    // Set up tree data provider
    this.dataProvider = new MyTreeDataProvider();
    this.refresh();
  }

  protected layoutBody(height: number, width: number): void {
    super.layoutBody(height, width);
  }
}

class MyTreeDataProvider implements ITreeViewDataProvider {
  async getChildren(element?: TreeNode): Promise<TreeNode[]> {
    if (!element) {
      // Root nodes
      return [
        { id: '1', label: 'Item 1' },
        { id: '2', label: 'Item 2' }
      ];
    }
    
    // Child nodes
    return [];
  }
}
```
</CodeGroup>

### Creating a Contribution

<CodeGroup>
```typescript IWorkbenchContribution
import { IWorkbenchContribution, IWorkbenchContributionsRegistry, Extensions as WorkbenchExtensions } from 'vs/workbench/common/contributions';
import { LifecyclePhase } from 'vs/workbench/services/lifecycle/common/lifecycle';
import { Registry } from 'vs/platform/registry/common/platform';

class MyWorkbenchContribution implements IWorkbenchContribution {
  constructor(
    @IEditorService private editorService: IEditorService,
    @INotificationService private notificationService: INotificationService
  ) {
    this.initialize();
  }

  private initialize(): void {
    // Listen for editor changes
    this.editorService.onDidActiveEditorChange(() => {
      const editor = this.editorService.activeEditor;
      if (editor) {
        this.notificationService.info(`Active editor: ${editor.getName()}`);
      }
    });
  }
}

// Register the contribution
Registry.as<IWorkbenchContributionsRegistry>(WorkbenchExtensions.Workbench)
  .registerWorkbenchContribution(
    MyWorkbenchContribution,
    LifecyclePhase.Restored // When to instantiate
  );
```

```typescript Lifecycle Phases
enum LifecyclePhase {
  // Before workbench UI is created
  Starting = 1,
  
  // After workbench UI is created but before restoration
  Ready = 2,
  
  // After editors and views are restored
  Restored = 3,
  
  // Eventually (low priority, after everything else)
  Eventually = 4
}

// Choose the right phase:
// - Starting: Critical infrastructure
// - Ready: UI contributions that should be visible immediately
// - Restored: Most contributions (wait for user data to load)
// - Eventually: Nice-to-have features, telemetry, etc.
```
</CodeGroup>

## Workbench Layout

The workbench layout is managed by the layout service:

<CodeGroup>
```typescript IWorkbenchLayoutService
interface IWorkbenchLayoutService {
  // Main container
  readonly container: HTMLElement;
  
  // Part visibility
  isVisible(part: Parts): boolean;
  setPartHidden(hidden: boolean, part: Parts): void;
  
  // Focus
  focus(): void;
  focusPart(part: Parts): void;
  
  // Dimensions
  getDimension(part: Parts): Dimension | undefined;
  
  // Sidebar
  readonly onDidChangeSideBarPosition: Event<Position>;
  getSideBarPosition(): Position;
  
  // Panel
  readonly onDidChangePanelPosition: Event<Position>;
  getPanelPosition(): Position;
  setPanelPosition(position: Position): void;
  
  // Layout
  layout(): void;
}

enum Parts {
  TITLEBAR_PART,
  ACTIVITYBAR_PART,
  SIDEBAR_PART,
  PANEL_PART,
  AUXILIARYBAR_PART,
  EDITOR_PART,
  STATUSBAR_PART
}
```

```typescript Using Layout Service
class MyComponent {
  constructor(
    @IWorkbenchLayoutService private layoutService: IWorkbenchLayoutService
  ) {}

  toggleSidebar(): void {
    const isVisible = this.layoutService.isVisible(Parts.SIDEBAR_PART);
    this.layoutService.setPartHidden(isVisible, Parts.SIDEBAR_PART);
  }

  movePanelToRight(): void {
    this.layoutService.setPanelPosition(Position.RIGHT);
  }
}
```
</CodeGroup>

## Context Keys

Context keys enable conditional UI and keybindings based on application state:

<CodeGroup>
```typescript Using Context Keys
import { IContextKeyService, RawContextKey } from 'vs/platform/contextkey/common/contextkey';

// Define context key
const IsMyViewVisible = new RawContextKey<boolean>('myView.visible', false);

class MyView {
  private isVisibleContext: IContextKey<boolean>;

  constructor(
    @IContextKeyService contextKeyService: IContextKeyService
  ) {
    // Bind context key
    this.isVisibleContext = IsMyViewVisible.bindTo(contextKeyService);
  }

  setVisible(visible: boolean): void {
    this.isVisibleContext.set(visible);
  }
}
```

```typescript Context Key Expressions
import { ContextKeyExpr } from 'vs/platform/contextkey/common/contextkey';

// Simple expression
const expr1 = ContextKeyExpr.equals('myView.visible', true);

// Complex expression
const expr2 = ContextKeyExpr.and(
  ContextKeyExpr.equals('myView.visible', true),
  ContextKeyExpr.not('editorReadonly'),
  ContextKeyExpr.regex('resourceScheme', /^file$/)
);

// Use in commands
CommandsRegistry.registerCommand({
  id: 'myView.action',
  handler: () => { /* ... */ },
  precondition: expr2
});
```
</CodeGroup>

Built-in context keys:
- `editorTextFocus` - Editor has focus
- `editorReadonly` - Editor is read-only
- `resourceScheme` - Resource URI scheme
- `isInDiffEditor` - Currently in diff editor
- And hundreds more...
