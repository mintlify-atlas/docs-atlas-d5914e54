## Overview

The platform layer (`src/vs/platform/`) provides core services and dependency injection infrastructure. It sits between the base utilities and higher-level components, offering cross-cutting concerns like configuration, logging, storage, and file access.

## Dependency Injection

### IInstantiationService

**Location:** `src/vs/platform/instantiation/common/instantiation.ts:41`

Core service for creating instances with automatic dependency injection:

```typescript
export interface IInstantiationService {
    readonly _serviceBrand: undefined;
    
    createInstance<T>(descriptor: SyncDescriptor0<T>): T;
    createInstance<Ctor extends new (...args: any[]) => any>(
        ctor: Ctor, 
        ...args: GetLeadingNonServiceArgs<ConstructorParameters<Ctor>>
    ): InstanceType<Ctor>;
    
    invokeFunction<R>(fn: (accessor: ServicesAccessor) => R): R;
    
    createChild(services: ServiceCollection): IInstantiationService;
}
```

### Creating Services

**Service Definition:**

```typescript
import { createDecorator } from 'vs/platform/instantiation/common/instantiation';

export const IMyService = createDecorator<IMyService>('myService');

export interface IMyService {
    readonly _serviceBrand: undefined;
    doSomething(): void;
}
```

**Service Implementation:**

```typescript
import { IMyService } from './myService';
import { IFileService } from 'vs/platform/files/common/files';
import { ILogService } from 'vs/platform/log/common/log';

export class MyService implements IMyService {
    declare readonly _serviceBrand: undefined;
    
    constructor(
        @IFileService private readonly fileService: IFileService,
        @ILogService private readonly logService: ILogService
    ) {
        this.logService.info('MyService created');
    }
    
    doSomething(): void {
        // Use injected services
    }
}
```

**Using Services:**

```typescript
export class MyWidget {
    constructor(
        @IMyService private readonly myService: IMyService,
        @IInstantiationService private readonly instantiationService: IInstantiationService
    ) {}
    
    createSomething() {
        // Create instances with DI
        const instance = this.instantiationService.createInstance(SomeClass);
    }
}
```

**2. Function Accessor**
```typescript
instantiationService.invokeFunction((accessor) => {

```

**3. Child Services**
```typescript
const childServices = new ServiceCollection();
childServices.set(IMyService, new MyService());
const child = instantiationService.createChild(childServices);
```

import { IConfigurationService } from 'vs/platform/configuration/common/configuration';

export class MyComponent {
    constructor(
        @IConfigurationService private readonly configService: IConfigurationService
    ) {
        // Read configuration
        const value = this.configService.getValue<string>('editor.fontSize');

## File Service {#files}

**Location:** `src/vs/platform/files/common/files.ts`

### IFileService

Unified file system operations across local and remote:

```typescript
import { IFileService } from 'vs/platform/files/common/files';
import { URI } from 'vs/base/common/uri';

export class FileManager {
    constructor(
        @IFileService private readonly fileService: IFileService
    ) {}
    
    async readFile(uri: URI): Promise<string> {
        const content = await this.fileService.readFile(uri);
        return content.value.toString();
    }
    
    async writeFile(uri: URI, content: string): Promise<void> {
        await this.fileService.writeFile(uri, 
            VSBuffer.fromString(content)
        );
    }
    
    async exists(uri: URI): Promise<boolean> {
        try {
            await this.fileService.resolve(uri);
            return true;
        } catch {
            return false;
        }
    }
}
```

### File Watching

```typescript
import { IFileService, FileChangeType } from 'vs/platform/files/common/files';

// Watch for file changes
fileService.onDidFilesChange(e => {
    for (const change of e.changes) {
        if (change.type === FileChangeType.UPDATED) {
            console.log('File updated:', change.resource.toString());
        }
    }
});

// Watch specific resources
const watcher = fileService.watch(URI.file('/path/to/watch'));

// Don't forget to dispose
watcher.dispose();
```

## Storage Service {#storage}

**Location:** `src/vs/platform/storage/common/storage.ts`

### IStorageService

Persistent key-value storage:

```typescript
import { IStorageService, StorageScope, StorageTarget } from 'vs/platform/storage/common/storage';

export class StateManager {
    private static readonly KEY = 'myComponent.state';
    
    constructor(
        @IStorageService private readonly storageService: IStorageService
    ) {}
    
    saveState(state: any): void {
        this.storageService.store(
            StateManager.KEY,
            JSON.stringify(state),
            StorageScope.WORKSPACE, // or StorageScope.PROFILE
            StorageTarget.USER
        );
    }
    
    loadState(): any {
        const stored = this.storageService.get(
            StateManager.KEY,
            StorageScope.WORKSPACE
        );
        return stored ? JSON.parse(stored) : null;
    }
    
    clearState(): void {
        this.storageService.remove(
            StateManager.KEY,
            StorageScope.WORKSPACE
        );
    }
}
```

### Storage Scopes

- **StorageScope.PROFILE** - User profile level (synced across workspaces)
- **StorageScope.WORKSPACE** - Workspace level (local to workspace)

## Service Registration

### Registering Services

**Location:** Service registration typically happens in `*.contribution.ts` files

```typescript
import { registerSingleton } from 'vs/platform/instantiation/common/extensions';
import { IMyService } from './myService';
import { MyService } from './myServiceImpl';

// Register as singleton
registerSingleton(IMyService, MyService, InstantiationType.Delayed);
```

### Instantiation Types

- **InstantiationType.Eager** - Created immediately
- **InstantiationType.Delayed** - Created when first requested

## Best Practices

<Warning>
**Service Lifetime:** Services are singletons per instantiation service. Don't store mutable state that should be instance-specific.
</Warning>

<Tip>
**Async Initialization:** Use lifecycle services if your service needs async initialization. Don't do heavy work in constructors.
</Tip>

<Note>
**Testing:** Create test-specific service implementations using `createDecorator` pattern for easy mocking.
</Note>

## Testing with Services
