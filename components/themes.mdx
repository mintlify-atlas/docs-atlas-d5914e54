## Overview

Themes in VS Code control the visual appearance of the editor, including syntax highlighting, UI colors, and icon themes. VS Code includes built-in themes and supports custom theme extensions.

**Locations:**
- `extensions/theme-*/` - Built-in color themes
- `src/vs/platform/theme/` - Theme infrastructure
- `src/vs/editor/common/editorTheme.ts` - Editor theming

## Token Colors {#token-colors}

**Location:** Theme files `tokenColors` section

### TextMate Scopes

```json
{
    "tokenColors": [
        {
            "scope": ["comment", "punctuation.definition.comment"],
            "settings": {
                "foreground": "#6A9955",
                "fontStyle": "italic"
            }
        },
        {
            "scope": ["keyword", "storage.type", "storage.modifier"],
            "settings": {
                "foreground": "#569CD6"
            }
        },
        {
            "scope": "string",
            "settings": {
                "foreground": "#CE9178"
            }
        },
        {
            "scope": "constant.numeric",
            "settings": {
                "foreground": "#B5CEA8"
            }
        },
        {
            "scope": ["entity.name.function", "support.function"],
            "settings": {
                "foreground": "#DCDCAA"
            }
        },
        {
            "scope": "entity.name.type.class",
            "settings": {
                "foreground": "#4EC9B0"
            }
        },
        {
            "scope": "variable",
            "settings": {
                "foreground": "#9CDCFE"
            }
        }
    ]
}
```

### Common TextMate Scopes

<Accordion title="Scope Reference">

- **comment** - Comments
- **string** - String literals
- **constant.numeric** - Numbers
- **constant.language** - Language constants (true, false, null)
- **keyword** - Keywords (if, for, return)
- **storage.type** - Type keywords (int, void, class)
- **storage.modifier** - Modifiers (public, static, const)
- **entity.name.function** - Function names
- **entity.name.type** - Type/class names
- **entity.name.tag** - HTML/XML tags
- **variable** - Variables
- **variable.parameter** - Function parameters
- **support.function** - Built-in functions
- **support.class** - Built-in classes
- **support.type** - Built-in types
- **meta.function-call** - Function calls
- **punctuation** - Punctuation characters
- **invalid** - Invalid/deprecated code

</Accordion>

## Theme Service

**Location:** `src/vs/platform/theme/common/themeService.ts`

### IThemeService Interface

```typescript
import { IThemeService, IColorTheme } from 'vs/platform/theme/common/themeService';
import { Color } from 'vs/base/common/color';

export class ThemedComponent {
    constructor(
        @IThemeService private readonly themeService: IThemeService
    ) {
        // Listen to theme changes
        this.themeService.onDidColorThemeChange(theme => {
            this.updateTheme(theme);
        });
        
        // Get current theme
        const currentTheme = this.themeService.getColorTheme();
        this.updateTheme(currentTheme);
    }
    
    private updateTheme(theme: IColorTheme): void {
        // Get theme colors
        const editorBg = theme.getColor('editor.background');
        const foreground = theme.getColor('editor.foreground');
        
        if (editorBg && foreground) {
            // Apply colors
            this.element.style.backgroundColor = editorBg.toString();
            this.element.style.color = foreground.toString();
        }
    }
}
```

### Theme Colors in Code

```typescript
import { registerColor } from 'vs/platform/theme/common/colorRegistry';
import { Color, RGBA } from 'vs/base/common/color';

// Register custom color
export const myCustomColor = registerColor(
    'myExtension.customColor',
    { dark: '#FF0000', light: '#00FF00', hcDark: '#0000FF', hcLight: '#00FF00' },
    'My custom color description'
);

// Use in code
const color = this.themeService.getColorTheme().getColor(myCustomColor);
```

## Best Practices

<Warning>
**Contrast:** Ensure sufficient contrast between foreground and background colors for readability.
</Warning>

<Tip>
**Consistency:** Keep color usage consistent across similar UI elements. Use the same colors for similar purposes.
</Tip>

<Note>
**Testing:** Test your theme in different lighting conditions and with various code samples.
</Note>

## Theme Testing

### Theme Color Tester

```typescript
// Test theme colors
import { IThemeService } from 'vs/platform/theme/common/themeService';

function testTheme(themeService: IThemeService): void {
    const theme = themeService.getColorTheme();
    
    console.log('Theme type:', theme.type); // 'dark', 'light', 'hc'
    console.log('Editor background:', theme.getColor('editor.background'));
    console.log('Editor foreground:', theme.getColor('editor.foreground'));
    
    // Test all colors
    const allColors = theme.defines(color => color);
    for (const [key, value] of allColors) {
        console.log(`${key}: ${value.toString()}`);
    }
}
```
