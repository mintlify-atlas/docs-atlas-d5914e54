# Installation Guide

This guide covers the prerequisites and platform-specific setup required to build Visual Studio Code from source.

<Warning>
  This guide is for building VS Code from source. If you want to use VS Code as an editor, download the pre-built binaries from [code.visualstudio.com](https://code.visualstudio.com/Download).
</Warning>

## System Requirements

### Minimum Requirements

- **RAM:** 4 GB minimum, 8-9 GB recommended for full builds
- **CPU:** 4 cores recommended for reasonable build times
- **Disk Space:** At least 5 GB for source code and build artifacts
- **Internet Connection:** Required for downloading dependencies

<Tabs>
  <Tab title="Windows">
    ## Windows Prerequisites
    
    ### Required Tools
    
    <Steps>
      <Step title="Install Node.js">
        Download and install Node.js from [nodejs.org](https://nodejs.org). Use the LTS version (22.x or later).
        
        Verify installation:
        ```powershell
        node --version
        npm --version
        ```
      </Step>
      
      <Step title="Install Python">
        Download and install Python 3.11 or later from [python.org](https://www.python.org/downloads/).
        
        <Warning>
          Make sure to check "Add Python to PATH" during installation.
        </Warning>
        
        Verify installation:
        ```powershell
        python --version
        ```
      </Step>
      
      <Step title="Install C++ Build Tools">
        Install Visual Studio 2022 Build Tools with the "Desktop development with C++" workload:
        
        1. Download from [Visual Studio Downloads](https://visualstudio.microsoft.com/downloads/)
        2. Select **Build Tools for Visual Studio 2022**
        3. In the installer, select **Desktop development with C++**
        4. Install the following individual components:
           - MSVC v143 - VS 2022 C++ x64/x86 build tools
           - Windows 11 SDK
           - C++ CMake tools for Windows
        
        <Note>
          The full Visual Studio IDE is not required, only the Build Tools.
        </Note>
      </Step>
      
      <Step title="Install Git">
        Download and install Git from [git-scm.com](https://git-scm.com/download/win).
        
        Verify installation:
        ```powershell
        git --version
        ```
      </Step>
    </Steps>
    
    ### Additional Tools (Optional)
    
    - **Windows Terminal** - Modern terminal with better support for development workflows
    - **PowerShell 7+** - Updated PowerShell with improved performance
    
    ### Building on Windows
    
    Once prerequisites are installed:
    
    ```powershell
    # Clone the repository
    git clone https://github.com/microsoft/vscode.git
    cd vscode
    
    # Install dependencies
    npm install
    
    # Run VS Code
    .\scripts\code.bat
    ```
    
    ### Windows-Specific Scripts
    
    ```powershell
    # Launch VS Code
    .\scripts\code.bat
    
    # Launch VS Code Server
    .\scripts\code-server.bat
    
    # Launch VS Code Web
    .\scripts\code-web.bat
    
    # Run CLI
    .\scripts\code-cli.bat
    ```
    
    ### Troubleshooting Windows
    
    <AccordionGroup>
      <Accordion title="node-gyp errors">
        Make sure Visual Studio Build Tools are properly installed with the C++ workload:
        
        ```powershell
        npm config set msvs_version 2022
        npm install
        ```
      </Accordion>
      
      <Accordion title="Python not found">
        Set the Python path explicitly:
        
        ```powershell
        npm config set python C:\Python311\python.exe
        ```
      </Accordion>
      
      <Accordion title="Long path issues">
        Enable long paths in Windows:
        
        1. Open Registry Editor
        2. Navigate to `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem`
        3. Set `LongPathsEnabled` to `1`
        
        Or use PowerShell (requires admin):
        ```powershell
        New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name "LongPathsEnabled" -Value 1 -PropertyType DWORD -Force
        ```
      </Accordion>
    </AccordionGroup>

  <Tab title="macOS">
    ## macOS Prerequisites
    
    ### Required Tools
    
    <Steps>
      <Step title="Install Xcode Command Line Tools">
        Install the Xcode Command Line Tools, which include essential build tools:
        
        ```bash
        xcode-select --install
        ```
        
        Verify installation:
        ```bash
        xcode-select -p
        # Should output: /Library/Developer/CommandLineTools
        ```
      </Step>
      
      <Step title="Install Homebrew (Recommended)">
        Install Homebrew for easy package management:
        
        ```bash
        /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
        ```
        
        <Tip>
          Follow the on-screen instructions to add Homebrew to your PATH.
        </Tip>
      </Step>
      
      <Step title="Install Node.js">
        Using Homebrew:
        ```bash
        brew install node
        ```
        
        Or download from [nodejs.org](https://nodejs.org).
        
        Verify installation:
        ```bash
        node --version
        npm --version
        ```
      </Step>
      
      <Step title="Install Git">
        Git is usually pre-installed on macOS. If not:
        
        ```bash
        brew install git
        ```
        
        Verify installation:
        ```bash
        git --version
        ```
      </Step>
      
      <Step title="Install Python (if needed)">
        macOS typically includes Python, but you may need to ensure Python 3 is available:
        
        ```bash
        brew install python3
        ```
        
        Verify installation:
        ```bash
        python3 --version
        ```
      </Step>
    </Steps>
    
    ### Building on macOS
    
    Once prerequisites are installed:
    
    ```bash
    # Clone the repository
    git clone https://github.com/microsoft/vscode.git
    cd vscode
    
    # Install dependencies
    npm install
    
    # Run VS Code
    ./scripts/code.sh
    ```
    
    ### macOS-Specific Scripts
    
    ```bash
    # Launch VS Code
    ./scripts/code.sh
    
    # Launch VS Code Server
    ./scripts/code-server.sh
    
    # Launch VS Code Web
    ./scripts/code-web.sh
    
    # Run CLI
    ./scripts/code-cli.sh
    ```
    
    ### Troubleshooting macOS
    
    <AccordionGroup>
      <Accordion title="Permission denied errors">
        Make scripts executable:
        
        ```bash
        chmod +x scripts/code.sh
        chmod +x scripts/code-server.sh
        chmod +x scripts/code-web.sh
        ```
      </Accordion>
      
      <Accordion title="Native module build fails">
        Ensure Xcode Command Line Tools are properly installed:
        
        ```bash
        sudo xcode-select --reset
        xcode-select --install
        ```
      </Accordion>
      
      <Accordion title="Slow npm install on macOS">
        Use a Docker volume for better performance:
        
        ```bash
        # Use Dev Containers instead
        # Or clone to a case-sensitive volume
        ```
        
        See the [Dev Container section](#using-dev-containers) for better performance.
      </Accordion>
    </AccordionGroup>
  </Tab>
  
  <Tab title="Linux">
    ## Linux Prerequisites
    
    ### Required Tools
    
    The following instructions are for Debian/Ubuntu-based distributions. Adjust package names for other distributions.
    
    <Steps>
      <Step title="Update Package Manager">
        ```bash
        sudo apt update
        sudo apt upgrade
        ```
      </Step>
      
      <Step title="Install Build Essentials">
        ```bash
        sudo apt install build-essential
        ```
        
        This includes:
        - gcc/g++ compilers
        - make
        - libc-dev
      </Step>
      
      <Step title="Install Node.js and npm">
        Install Node.js 22.x or later:
        
        ```bash
        # Using NodeSource repository
        curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
        sudo apt install -y nodejs
        ```
        
        Verify installation:
        ```bash
        node --version
        npm --version
        ```
      </Step>
      
      <Step title="Install Git">
        ```bash
        sudo apt install git
        ```
        
        Verify installation:
        ```bash
        git --version
        ```
      </Step>
      
      <Step title="Install Additional Dependencies">
        Install libraries required for building native modules:
        
        ```bash
        sudo apt install -y \
          libx11-dev \
          libxkbfile-dev \
          libsecret-1-dev \
          libkrb5-dev \
          python3 \
          pkg-config
        ```
      </Step>
    </Steps>

    <AccordionGroup>

        ```bash
        chmod +x scripts/code-web.sh
        ```
      </Accordion>
      
      <Accordion title="Missing libraries">
        If you encounter missing library errors, install the development packages:
        
        ```bash
        # For Ubuntu/Debian

        # For Fedora
        ```

        If running in a headless environment or container, you may need X11 forwarding or a virtual display:
        
        ```bash

        sudo apt install xvfb
        
        # Run with virtual display
        xvfb-run -a ./scripts/code.sh
        ```

## Using Dev Containers

For a consistent development environment across all platforms, use the included dev container configuration.

### Prerequisites

- [Docker Desktop](https://www.docker.com/products/docker-desktop) (Windows/macOS) or Docker Engine (Linux)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)

### System Requirements for Containers

<Warning>
  Docker needs at least **4 Cores and 8 GB of RAM** to run a full build, with **9 GB of RAM** recommended.
</Warning>

On macOS or Windows with Docker Desktop:
1. Right-click the Docker icon in the system tray
2. Go to **Settings > Resources > Advanced**
3. Increase CPU cores to 4+ and memory to 8+ GB
4. Click **Apply & Restart**

### Using the Dev Container

<Steps>
  <Step title="Open VS Code">
    Launch Visual Studio Code on your machine.
  </Step>
  
  <Step title="Clone in Container">
    Press `Ctrl/Cmd + Shift + P` and select:
    
    **Dev Containers: Clone Repository in Container Volume...**
    
    Enter the repository URL:
    ```
    https://github.com/microsoft/vscode
    ```
    
    <Tip>
      Using a container volume provides better performance than mounting your local filesystem.
    </Tip>
  </Step>
  
  <Step title="Wait for Container Setup">
    The container will automatically:
    - Pull the required Docker images
    - Set up the development environment
    - Install all dependencies
    
    This may take 10-20 minutes on first run.
  </Step>
  
  <Step title="Build and Run">
    Once the container is ready:
    
    ```bash
    npm install
    ./scripts/code.sh
    ```
    
    The graphical VS Code will appear in the VNC viewer.
  </Step>
</Steps>

### Accessing the Desktop Environment

The dev container includes a desktop environment accessible via:

- **Web Browser:** Navigate to [http://localhost:6080](http://localhost:6080)
- **VNC Client:** Connect to `localhost:5901` with password `vscode`

<Note>
  The Resource Monitor extension is included in the container to help you monitor CPU and memory usage in the status bar.
</Note>

## GitHub Codespaces

GitHub Codespaces provides a cloud-based development environment.

<Steps>
  <Step title="Create Codespace">
    1. Go to [github.com/microsoft/vscode](https://github.com/microsoft/vscode)
    2. Click the **Code** dropdown
    3. Select **Codespaces** tab
    4. Click **Create codespace on main**
    5. Choose **4-core** machine (or larger)
  </Step>
  
  <Step title="Access Desktop">
    Once the Codespace is running:
    
    1. Press `Ctrl/Cmd + Shift + P`
    2. Select **Ports: Focus on Ports View**
    3. Find port **6080** (VNC web client)
    4. Click the globe icon to open in browser
    5. Click **Connect** and enter password `vscode`
  </Step>
  
  <Step title="Build and Run">
    In the Codespace terminal:
    
    ```bash
    npm install
    ./scripts/code.sh
    ```
    
    VS Code will appear in the VNC viewer.
  </Step>
</Steps>

## Verifying Your Installation

After installation, verify everything works:

```bash
# Check Node.js
node --version

# Check npm
npm --version

# Check Git
git --version

# Check Python (Linux/macOS)
python3 --version

# Check Python (Windows)
python --version
```

### Test Build

```bash
# Clone repository
git clone https://github.com/microsoft/vscode.git
cd vscode

# Install dependencies
npm install

# Compile code
npm run compile

# Run VS Code
./scripts/code.sh      # Linux/macOS
.\scripts\code.bat     # Windows
```

If VS Code launches successfully, your installation is complete!
