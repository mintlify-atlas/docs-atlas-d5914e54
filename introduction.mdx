## What is Visual Studio Code?

Visual Studio Code is a free, open-source code editor built with TypeScript, web technologies, and Electron. It combines the simplicity of a code editor with powerful features developers need for their core edit-build-debug cycle.

This repository ("Code - OSS") is where Microsoft develops Visual Studio Code together with the community. The source code is available to everyone under the standard [MIT license](https://github.com/microsoft/vscode/blob/main/LICENSE.txt).

## Architecture Highlights

VS Code is built with a layered architecture designed for extensibility and performance:

<Steps>
  <Step title="Base Layer">
    Foundation utilities and cross-platform abstractions in `src/vs/base/` provide core functionality like lifecycle management, events, and data structures
  </Step>
  <Step title="Platform Services">
    Dependency injection infrastructure in `src/vs/platform/` powers the service-based architecture used throughout the codebase
  </Step>
  <Step title="Editor Core">
    The Monaco editor in `src/vs/editor/` delivers rich text editing with language services and syntax highlighting
  </Step>
  <Step title="Workbench">
    The main application shell in `src/vs/workbench/` provides the UI, view management, and feature contributions
  </Step>
</Steps>

/**
 * Dependency injection service for creating instances with automatic
 * service resolution
 */
export interface IInstantiationService {
  readonly _serviceBrand: undefined;

  /**
   * Synchronously creates an instance that is denoted by the descriptor
   */
  createInstance<T>(descriptor: SyncDescriptor0<T>): T;
  createInstance<Ctor extends new (...args: any[]) => unknown>(
    ctor: Ctor,
    ...args: GetLeadingNonServiceArgs<ConstructorParameters<Ctor>>
  ): InstanceType<Ctor>;

  /**
   * Calls a function with a service accessor
