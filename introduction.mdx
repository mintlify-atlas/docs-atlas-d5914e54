# Visual Studio Code - Open Source

Visual Studio Code combines the simplicity of a code editor with what developers need for their core edit-build-debug cycle. It provides comprehensive code editing, navigation, and understanding support along with lightweight debugging, a rich extensibility model, and lightweight integration with existing tools.

<Note>
  This repository ("Code - OSS") is where Microsoft develops Visual Studio Code together with the community. The source code is available under the [MIT license](https://github.com/microsoft/vscode/blob/main/LICENSE.txt).
</Note>

## Architecture Overview

Visual Studio Code is built with a layered architecture using TypeScript, web APIs, and Electron, combining web technologies with native app capabilities.

### Core Layers

<AccordionGroup>
  <Accordion title="Base Layer (src/vs/base/)">
    Foundation utilities and cross-platform abstractions providing common functionality used throughout the codebase.
  </Accordion>
  
  <Accordion title="Platform Layer (src/vs/platform/)">
    Platform services and dependency injection infrastructure. Services are injected through constructor parameters following a strict layering model.
  </Accordion>
  
  <Accordion title="Editor Layer (src/vs/editor/)">
    Text editor implementation powered by Monaco Editor, including language services, syntax highlighting, and editing features.
  </Accordion>
  
  <Accordion title="Workbench Layer (src/vs/workbench/)">
    Main application workbench for web and desktop:
    - **browser/** - Core workbench UI components (parts, layout, actions)
    - **services/** - Service implementations
    - **contrib/** - Feature contributions (git, debug, search, terminal)
    - **api/** - Extension host and VS Code API implementation
  </Accordion>
  
  <Accordion title="Electron Main Process (src/vs/code/)">
    Electron main process specific implementation for desktop applications.
  </Accordion>
  
  <Accordion title="Server Implementation (src/vs/server/)">
    Server-specific implementation for remote development scenarios.
  </Accordion>
</AccordionGroup>

### Architecture Principles

- **Layered Architecture** - Code is organized in layers from base → platform → editor → workbench
- **Dependency Injection** - Services are injected through constructor parameters with non-service parameters coming after service parameters
- **Contribution Model** - Features contribute to registries and extension points
- **Cross-platform Compatibility** - Abstractions separate platform-specific code

## Repository Structure

```
vscode/
├── src/                 # Main TypeScript source code
│   ├── vs/
│   │   ├── base/       # Foundation utilities
│   │   ├── platform/   # Platform services
│   │   ├── editor/     # Monaco Editor
│   │   ├── workbench/  # Main application
│   │   ├── code/       # Electron main process
│   │   └── server/     # Server implementation
├── extensions/         # Built-in extensions
├── build/             # Build scripts and CI/CD
├── test/              # Integration tests
├── scripts/           # Development scripts
├── resources/         # Static resources
└── out/               # Compiled output (generated)
```

## Built-in Extensions

VS Code includes a rich set of built-in extensions in the `extensions/` folder:

- **Language Support** - TypeScript, HTML, CSS, JSON, Markdown, and more
- **Core Features** - Git integration, debugging, Emmet, search
- **Themes** - Default color themes and icon themes
- **Development Tools** - Extension authoring and API testing

Each extension follows the standard VS Code extension structure with `package.json`, TypeScript sources, and contribution points.

## Contributing

There are many ways to participate in this project:

- Submit bugs and feature requests on [GitHub Issues](https://github.com/microsoft/vscode/issues)
- Review source code changes in [Pull Requests](https://github.com/microsoft/vscode/pulls)
- Contribute to the [documentation](https://github.com/microsoft/vscode-docs)
- Fix issues and contribute directly to the code base

<Tip>
  See the [How to Contribute](https://github.com/microsoft/vscode/wiki/How-to-Contribute) wiki page for detailed information on the development workflow, debugging, coding guidelines, and submitting pull requests.
</Tip>
