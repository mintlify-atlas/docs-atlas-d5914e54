# Quickstart Guide

This guide will help you get Visual Studio Code running from source quickly so you can start contributing to the project.

<Note>
  This quickstart is for contributors who want to build and run VS Code from source. If you just want to use VS Code, download it from [code.visualstudio.com](https://code.visualstudio.com).
</Note>

## Prerequisites

Before you begin, make sure you have:

- **Git** installed on your system
- **Node.js** (version specified in package.json)
- **npm** (comes with Node.js)
- At least **4 GB RAM** (8 GB recommended for full builds)

<Warning>
  Docker containers and Codespaces need at least **4 Cores and 6 GB of RAM** (8 GB recommended) to run a full build.
</Warning>

## Quick Start Steps

<Steps>
  <Step title="Clone the Repository">
    Clone the VS Code repository from GitHub:
    
    ```bash
    git clone https://github.com/microsoft/vscode.git
    cd vscode
    ```
    
    <Tip>
      On macOS and Windows, using a Docker volume or WSL filesystem provides better disk I/O performance than the native filesystem.
    </Tip>
  </Step>
  
  <Step title="Install Dependencies">
    Install all required dependencies using npm:
    
    ```bash
    npm install
    ```
    
    This command runs the `postinstall` script automatically, which sets up additional build dependencies and downloads required binaries.
    
    <Note>
      The first install may take several minutes depending on your internet connection and system performance.
    </Note>
  </Step>
  
  <Step title="Run VS Code from Source">
    Start VS Code in development mode using the provided script:
    
    **On Linux/macOS:**
    ```bash
    ./scripts/code.sh
    ```
    
    **On Windows:**
    ```bash
    .\scripts\code.bat
    ```
    
    This will compile the necessary files and launch VS Code with Electron.
  </Step>
  
  <Step title="Start Watching for Changes (Optional)">
    For active development, start the watch mode to automatically recompile on file changes:
    
    ```bash
    npm run watch
    ```
    
    This runs multiple watch tasks in parallel:
    - `watch-client-transpile` - Transpiles TypeScript files
    - `watch-client` - Watches client code changes
    - `watch-extensions` - Watches built-in extensions
    
    <Tip>
      You can also use `npm run watchd` to run the watch tasks as a daemon that persists across terminal sessions.
    </Tip>
  </Step>
</Steps>

## Available Build Scripts

Here are the most commonly used npm scripts for development:

### Compilation

```bash
# Compile the entire project
npm run compile

# Compile just the CLI
npm run compile-cli

# Compile web version
npm run compile-web
```

### Running VS Code

```bash
# Launch VS Code (desktop)
./scripts/code.sh          # Linux/macOS
.\scripts\code.bat          # Windows

# Launch VS Code Server
./scripts/code-server.sh   # Linux/macOS
.\scripts\code-server.bat   # Windows

# Launch VS Code Web
./scripts/code-web.sh      # Linux/macOS
.\scripts\code-web.bat      # Windows
```

<Note>
  The web version runs VS Code in your browser at `http://localhost:8080` by default.
</Note>

### Testing

```bash
# Run unit tests (browser)
npm run test-browser

# Run unit tests (Node.js)
npm run test-node

# Run extension tests
npm run test-extension

# Run integration tests
./scripts/test-integration.sh   # Linux/macOS
.\scripts\test-integration.bat   # Windows
```

### Code Quality

```bash
# Run ESLint
npm run eslint

# Run hygiene checks
npm run hygiene

# Check for cyclic dependencies
npm run check-cyclic-dependencies

# Validate layering architecture
npm run valid-layers-check
```

## Development Container

VS Code includes a development container configuration for easier setup using Docker or GitHub Codespaces.

### Using Dev Containers (Local)

<Steps>
  <Step title="Install Prerequisites">
    - Install [Docker Desktop](https://www.docker.com/products/docker-desktop)
    - Install [VS Code](https://code.visualstudio.com/)
    - Install the [Dev Containers extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers)
  </Step>
  
  <Step title="Clone in Container">
    Press `Ctrl/Cmd + Shift + P` and select:
    
    **Dev Containers: Clone Repository in Container Volume...**
    
    Enter the repository URL:
    ```
    https://github.com/microsoft/vscode
    ```
  </Step>
  
  <Step title="Build and Run">
    Once the container is ready, open a terminal and run:
    
    ```bash
    npm install
    ./scripts/code.sh
    ```
  </Step>
</Steps>

### Using GitHub Codespaces

<Steps>
  <Step title="Create a Codespace">
    1. Go to the [VS Code repository](https://github.com/microsoft/vscode)
    2. Click the **Code** dropdown
    3. Select **Open with Codespaces**
    4. Click **New codespace**
    5. Choose **Standard** machine size (4-core, 8GB RAM)
  </Step>
  
  <Step title="Build in Codespace">
    The Codespace will automatically set up the environment. Once ready:
    
    ```bash
    npm install
    ./scripts/code.sh
    ```
  </Step>
</Steps>

<Tip>
  The dev container includes a VNC server for running the graphical VS Code instance. Connect to `localhost:6080` in your browser or use a VNC client on port `5901` with password `vscode`.
</Tip>

## Debugging VS Code

VS Code includes launch configurations for debugging:

1. Open the **Run and Debug** view (`Ctrl/Cmd + Shift + D`)
2. Select the **VS Code** launch configuration from the dropdown
3. Press `F5` to start debugging

This will:
- Compile the source code
- Launch VS Code with the debugger attached
- Allow you to set breakpoints and inspect the code

<Warning>
  If launching times out, you can increase the `timeout` value in the launch configurations found in `.vscode/launch.json`. Running `./scripts/code.sh` first usually resolves timeout issues.
</Warning>

## Common Issues

<AccordionGroup>
  <Accordion title="npm install fails">
    Make sure you have the correct Node.js version installed. Check the `engines` field in `package.json` for the required version.
    
    Try clearing npm cache:
    ```bash
    npm cache clean --force
    npm install
    ```
  </Accordion>
  
  <Accordion title="Out of memory errors during build">
    Increase Node.js memory limit:
    ```bash
    export NODE_OPTIONS="--max-old-space-size=8192"
    npm run compile
    ```
  </Accordion>
  
  <Accordion title="Electron download fails">
    The build script automatically downloads Electron. If it fails, check your network connection and proxy settings.
    
    You can manually download Electron:
    ```bash
    npm run electron
    ```
  </Accordion>
  
  <Accordion title="scripts/code.sh won't launch">
    Make sure the script is executable:
    ```bash
    chmod +x scripts/code.sh
    ./scripts/code.sh
    ```
  </Accordion>
</AccordionGroup>
